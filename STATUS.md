# STATUS.md — GoNext

## Зафиксированные решения

1. **Прототип — эталон.** Визуал и структура экранов берутся из `gonext_prototype.html` / копии в `docs/reference/`. Без согласования с владельцем не менять.
2. **Оригинал прототипа не редактируется.** Работа только с копией `docs/reference/gonext_prototype.html` (путь оригинала и копии — в README).
3. **Стек MVP:** Expo SDK 54, Expo Router, React Native Paper, SQLite локально, без сервера и без аккаунта.
4. **Модель данных** — по `PROJECT_GoNext.md` (поля `visitLater`, `dayNumber`, связи через `placeId`). Имена в прототипе (`want`, `day`, вложенные места идеи) при переносе нормализуются к PROJECT.
5. **Архитектура:** UI → hooks/services → repositories → SQLite (без SQL из компонентов).
6. **Документация Expo:** читать `https://docs.expo.dev/versions/v54.0.0/` (`AGENTS.md` исправлен с v57 на v54).
7. **Версия:** единственный источник `constants/version.js` → `__version__` (+ `formatAppVersion`, `getInstallerBaseName`). Не хардкодить номер в других файлах.
8. **Завершение этапа:** коммит + пуш в формате вехи `feat: этап N — … (vX.Y.Z)`; см. README и PLAN.
9. **Поиск:** обязателен двунаправленный маппинг ошибочной раскладки ЙЦУКЕН↔QWERTY.
