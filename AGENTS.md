# Expo HAS CHANGED

Read the exact versioned docs at https://docs.expo.dev/versions/v54.0.0/ before writing any code.

## Ритуал этапа (обязательно)

1. **Новый этап → новый чат.** Не начинать этап N+1 в том же чате, где закрыли N.
2. Перед работой: `docs/BACKLOG.md`, затем `PLAN.md`.
3. После реализации — **подробный чек-лист проверки** владельцу; **не** коммитить/пушить до «кип» / «ок на кип».
4. По «кип»: коммит + пуш вехи, обновить PLAN/STATUS/TIME/девлог/`__version__`.
5. После кип — напомнить владельцу открыть **новый чат** на следующий этап.

Подробности: `PLAN.md` → «Ритуал этапа», `README.md`.

## Команда владельца: «полный статус»

Ответ = актуальная таблица из `STATUS.md` → раздел **Полный статус** (этапы 0→10). Не сокращать до чек-листа. После закрытия этапа обновлять ту таблицу.
